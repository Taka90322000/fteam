# マチリク テーブル設計書

- **システム名称**：マチリク（宇都宮市 空き店舗マッチング・地域需要プラットフォーム）
- **対象DBMS**：PostgreSQL 17（PostGIS 拡張利用）
- **設計規模**：全 40 テーブル・全 349 項目（業務テーブルのみ。PostGIS システム表 `spatial_ref_sys` を除く）
- **最終改訂日**：2026-11-25
- **記法**：`PK`＝主キー、`FK`＝外部キー、`NN`＝NOT NULL（`○` が該当）。初期値の `自動採番` は `GENERATED BY DEFAULT AS IDENTITY` を表す。

## 5. 設計の前提と業務ルール

- **認証とプロフィール分離**：会員認証はLINEログイン（`users.line_subject` 必須・ハッシュ保存）に一本化し、パスワード列は持たない。電話番号・アイコン参照先は `users` ではなく `business_profiles` および `owner_profiles` に保持する（主番号必須・追加番号任意・共有事業所番号を許容するため一意制約なし）。
- **空間データ（PostGIS）**：事業主の出店希望範囲は `business_profiles.area` に `GEOMETRY(Polygon, 4326)` として保存し、GiSTインデックスと `ST_IsValid` / `NOT ST_IsEmpty` 制約で妥当性を保証する。
- **物件詳細と諸費用規約**：`properties` の敷金・礼金・保証金は「未選択＝なし（`NONE`）」に統一し、区分コード（`*_kind`）と月数・金額列の組み合わせを `CHECK` 制約で保証する。坪面積は `floor_area_sqm` からの算出値とし重複保存しない。
- **設備・業種・資格のマスタ正規化**：基本インフラ設備（`facilities` / `property_facilities`）、業種（`industry_categories` / `industry_types` / `property_industries`）、資格・要件（`qualifications` / `business_qualifications`）はすべてマスタ＋中間テーブルで管理し、有効フラグと表示順で拡張可能とする。
- **順位投票と需要スコア**：`property_votes` の `UNIQUE(property_id, resident_user_id)` と `vote_choices` の複合PK・小分類一意制約により、1人1物件・順位1〜3・重複不可を保証する。明細スコアは `rank_weight / (1 + distance_km / distance_scale_km)` で算出し、集計値は基礎データから算出する。
- **アンケート・クーポン**：来店アンケートの固定満足度は `survey_responses.rating` に必須保存し、追加設問は番号2〜10（最大9問）とする。改訂元は `surveys.previous_survey_id` で追跡し、未使用クーポンの無効化は `coupon_recipients.revoked_at` に記録する。
- **運営管理・問い合わせ・通報**：運営権限は `admin_members`、状態変更・掲載停止（`properties.admin_hidden_at` 等）の操作履歴は `admin_audit_logs`、問い合わせは `inquiries` / `inquiry_messages`、通報は `reports` で管理する。
- **削除方針**：参照される会員・物件・マスタ・契約・回答・管理履歴は原則 `ON DELETE RESTRICT` で物理削除を防ぎ、退会日時・削除日時・有効フラグ・掲載停止日時で制御する。
- **日時とロール権限**：日時はすべて `TIMESTAMPTZ`（UTC保存・画面は日本時間表示）とする。アプリ用ロール `machiriku_app` へは必要な最小権限のみを付与し、DDL変更はDB所有者（`postgres` 等）で実行する。
